1. Go to [takeout.google.com](https://takeout.google.com)
2. Deselect all products, then select only 'YouTube and YouTube Music'
3. Click 'All YouTube data included', then select only 'history'
4. Choose JSON format (not HTML)
5. Export and download the archive
6. Extract the archive and find 'watch-history.json'
7. Upload that file here
